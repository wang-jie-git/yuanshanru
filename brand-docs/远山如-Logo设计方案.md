# ⭐ v2.0 采纳决议（2026-10-11）

## 主推方案：双峰叠领 · 镜相对齐

**三位一体隐喻**：
- **象（远山）**：远山之起伏 = 身形骨相曲线，东方审美最耐看的沉静从容
- **器（衣领）**：两条交叠山脊 = 宋制"交领右衽"衣襟交叠
- **理（对齐）**：左线=人（身形体态档案），右线=衣（商品属性档案），中央黄金分割点交汇相契 = 双档案对齐引擎

**图形结构**：
- 两道微弧曲线：左弧稍高而缓（人/骨相/包容），右弧稍低而挺（衣/版型/立骨）
- 交叠处形成向内收拢的 V 形衣领轮廓，整体如远山隐于云气
- 底部完全开放不封口（计白当黑 / 气韵流通）

## 工程规范补充（v2.1，2026-10-11 · 服装产线级细节）

> 来源：设计评审——主 Logo 的紫灰水墨渐变在屏幕/铜版纸印刷上完美，但在服装极端工艺（织唛/水洗标/金属激光雕刻/单色热转印）下细微渐变易糊。追加以下三套规范：

### 1. 单色线条版（Monochrome Flat Version）· 产线必备

- **用途**：领标织唛、水洗标、金属纽扣激光雕刻、单色热转印、盖章/压印
- **形态**：山峦部分用**单色块或留白线条**呈现，完全去除水墨渐变，两层山脊用正负形（实色块 + 留白线）区分
- **色**：纯单色（黛紫灰 #5A5A6E 或纯黑），无渐变、无叠加
- **验收**：任何粗糙材质（棉织唛/金属/热转印膜）下不失真、不糊片

### 2. Micro-Icon（≤16px 极端尺寸版）· 图标可读性

- **用途**：16px Favicon、手机桌面 60×60 图标、系统托盘
- **形态**：**去印章**（印章在此尺寸会像坏点）、**交点线条加粗**（中央交汇点放大为实心节点）
- **逻辑**：小尺寸下只保留"双峰叠领"的可读轮廓，牺牲细节保辨识
- **验收**：60×60 像素下仍一眼可辨是"山+领"而非污点

### 3. 印章字定稿：「得体」

- **篆刻内容**：**「得体」** 二字（非"远山"/"如山"）
- **理由**：得体 = 恰如其分 = "远山如"之"如"的语义展开；品牌卖判断力，判断力终点即得体；二字左右结构篆刻稳
- **法度**：仿宋人书画压角印，白文（字白底朱）或朱文（字朱底白）按场景选，尺寸 4-8px（相对主标）
- **验收**：放大镜推敲——二字结构经得起看，不糊不散

## 二、设计目标与原则

### 目标
一个 Logo，同时做到三件事：
1. **一眼认出"远山如"**——汉字字标是主载体（宋体/楷体），图形标是辅助识别
2. **说清"判断力"**——符号里藏着"尺 / 对齐 / 定论"的语义
3. **撑起宋韵**——黛色远山 + 留白 + 印章感，克制不喧哗

### 原则（含禁忌）
- ✅ 主色过**灰调三规律**（S≤45 / 色相≤2 / L30-70）——参考锚点黛紫灰 #5A5A6E
- ✅ 朱砂只作**印章级点睛**（≤3%，呼应官网 CTA 红）
- ✅ 图形允许**高辨识度的负空间与几何构造**（远山、尺、卡）
- ❌ 不用西式光谱撞色（渐变紫/蓝、三色对峙）
- ❌ 不用"仙侠古风"贴图（水墨晕染、竹林仙鹤、飘带）
- ❌ 不用廉价拟物（衣架实物、针线、剪刀图标）
- ❌ 不堆字——"远山如"三字足矣，副文案不进主标

## 三、核心符号逻辑 · 三个概念方向

### 方向 A ——「远山如黛」· 汉字字标 + 山形负空间

**构造**：
- 主标：**「远山如」三个字**，思源宋体/清刻本悦宋类，字距微松
- 图形标：**三段式远山**（近山/远山/天边一线），黛紫灰主色
- 负空间机关：**两山之间的留白，藏一把尺的刻度**（远山轮廓的上沿＝尺的刻度线）
- 可选点睛：山脚下一点**朱砂印章**（圆章刻"如"字，或方章刻"远山如"）

**语义**：名字即意象（远山如黛）＋ 承诺即尺度（尺＝"人该穿什么"的度量衡）
**适用**：官网 favicon、导航、名片、决策卡卡面
**变体**：可单用字标（小场景）／单用山形（app 图标）／字标+山形（主场景）

```
         ＿                ← 尺刻度线（负空间）
       ／＼        ＿
     ／   ＼    ／＼
   ／ 远 山 ＼／   ＼     ← 三段式远山
  ／如       ＼     ＼
 ◇ 印章点（朱砂）         ← 点睛
```

### 方向 B ——「印章定论」· 朱砂方印式

**构造**：
- 主标：**篆书/楷书「远山如」三字**，置于方印内（印边 1-1.5px）
- 印身颜色：**黛紫灰**（主色），或 **朱砂**（限 ≤3% 场景：名片角标、决策卡印章位）
- 印底：宣纸纹理（暖灰白 #EDEBE4），边缘微残（仿朱泥印）

**语义**：印章＝**定论/权威/判断**——"诊断出结果，盖章为凭"，与决策卡产品语义同构
**适用**：决策卡背面"诊断章"、微信头像、招商物料、授权书
**变体**：方印（正式）／圆印（轻量）／缺角印（现代感）

### 方向 C ——「双山对位」· 双档案对齐

**构造**：
- 图形标：**两座山相对**（左山=顾客档案，右山=商品档案），中间留白形成**一张卡的轮廓**
- 卡内可藏**「如」字**或**对齐刻度线**
- 配色：左山黛紫灰，右山雾灰蓝 #8A9BB0（色相 1 蓝系，过律 2）

**语义**：产品最硬的内核——**她×它＝一张卡**（双档案对齐）。行业里没有第二家用这个符号
**适用**：产品线 Logo、决策卡正面、双智能体架构的可视化标识
**变体**：全图形（不用字）／图形+字标横排

```
      ／＼          ／＼
    ／   ＼  卡   ／   ＼     ← 中间负空间＝一张卡
  ／ 她档案 ＼───／ 它档案 ＼
```

## 四、推荐方案

### 首选：方向 A（字标为主）+ 方向 B 点睛（印章为辅）
- **主场景**：字标「远山如」（宋体）+ 山形负空间尺刻度 → 官网 nav / 名片 / 招商页
- **印章场景**：朱砂方印「远山如」→ 决策卡"诊断章"、微信头像、物料落款
- **产品场景**：方向 C 的双山对位卡形 → 决策卡正面 / 产品介绍

一套体系、三个场景，互不打架——这符合"品牌系统"而非"一个图标"的标准。

### 理由
1. **名字即资产**：远山如三个字本身是宋韵意象，汉字字标辨识度最高、最不可抄袭
2. **尺/印章双隐喻**：尺=判断力（Slogan 落地），印章=定论（产品语义），都是"专业判断"的宋式表达
3. **可延展**：能自然衍生出黛青阁（子品牌＝黛青色调山形+阁字印）、决策卡（卡形符号）

> 校准点：官网现黛青 #243447 偏现代深蓝 → Logo 采用宋韵黛青系 **黛紫灰 #5A5A6E**（S≈18%，过律 1/2/3），主场景与官网可共存（官网浅底用 #243447 是"宋骨现代"表达，Logo 深底用 #5A5A6E 是"宋韵原味"表达，不冲突）。

| 角色 | 色名 | 色值 | 依据 |
|---|---|---|---|
| **主色** | 黛紫灰 | #5A5A6E | 宋韵扩展表（黛青当代变体，远山墨色加紫灰，S≈18% L≈42） |
| **辅色** | 雾灰蓝 | #8A9BB0 | 方向 C 右山，天青当代变体（S≈20%） |
